# Weather App

A React weather search application that retrieves current conditions by city from OpenWeather.

## Displays

- Current, minimum, and maximum temperature
- Feels-like temperature
- Humidity
- Weather description

## Tech stack

React, Vite, Material UI, OpenWeather API

## Run locally

```bash
npm install
cp .env.example .env
npm run dev
```

Set `VITE_OPENWEATHER_API_KEY` in `.env` and restrict the key in the provider dashboard.
